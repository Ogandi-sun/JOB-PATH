# JOB PATH – Group Project v2

Unified frontend using your **style2** color system (indigo, cyan, navy, gold).

## Files

| File | Page |
|------|------|
| `index.html` | Home – hero, 3 steps, CTAs |
| `jobs.html` | Jobs list, search, filters, apply modal |
| `about.html` | About (spaced sections) |
| `contact.html` | Contact form |
| `style.css` | Shared design system |

## Colors (from style2)

- Indigo: `#4f46e5`
- Cyan: `#06b6d4`
- Navy: `#0f172a`
- Gold (buttons): `#ffb627`

## Logo

Put the logo here:

- Preferred: `Images/logo.jpeg`
- Or: `logo.jpeg` in this folder

If missing, text **JOB PATH** is shown.

## Links

- Navbar + footer on every page: Home, Jobs, About, Contact
- Browse Jobs / Apply / Get Started buttons linked
- Jobs apply modal + success toast
- Contact form success toast (demo)

## About page – spacing fix

Original About was one dense block of headings/paragraphs.

**What changed:**
1. Hero banner with title + intro
2. Separate sections with vertical padding
3. Alternating white / light backgrounds
4. Mission & Vision in two columns
5. Values as three cards with icons
6. Clear list spacing
7. Bottom gold CTA linking to Jobs
8. Same nav/footer as other pages

## How to open

1. Extract this folder
2. Add logo under `Images/logo.jpeg` (optional)
3. Open `index.html` in a browser or use VS Code Live Server

No npm install needed.
